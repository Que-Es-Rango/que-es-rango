# que-es-rango
Que Es Rango reúne una guía visual y curada para entender qué significa rango en matemáticas, funciones y hojas de cálculo. Que Es Rango combina explicaciones breves, ejemplos prácticos, referencias sobre dominio y rango, cálculo del rango, Geogebra y rango en Excel en un recurso claro y fácil de consultar.
